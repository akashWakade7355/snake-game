# Snake Game

A neon retro Snake Game built with HTML5, CSS3, and vanilla JavaScript. It is designed to match the provided mockup while delivering playable gameplay, local storage persistence, sound effects, touch controls, and GitHub Pages deployment support.

## Features
- Neon-green retro game UI styled to match the reference design.
- Canvas-based Snake gameplay with keyboard and touch controls.
- Speed, skin, mute, and high-score persistence through LocalStorage.
- Pause, restart, and game-over overlays.
- Responsive layout for desktop, tablet, and mobile.
- GitHub Pages-ready static site.

## Local setup
1. Clone the repository.
2. From the project root, run:
   ```bash
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.

## Controls
- Arrow keys or WASD to move.
- Spacebar to pause or resume.
- Restart button to begin a new run.
- On-screen touch buttons are available on smaller screens.

## Deployment
This project is ready to deploy via GitHub Pages from the repository root on the `main` branch.
