## About

A neon retro Snake Game built with HTML5 Canvas, CSS, and vanilla JavaScript. Chase your high score with responsive keyboard and touch controls, customizable snake skins, adjustable speed, sound effects, and saved preferences.

**Play the deployed game:** [akashwakade7355.github.io/snake-game](https://akashwakade7355.github.io/snake-game/)

## Features

- Canvas-based Snake gameplay with keyboard and touch controls.
- Neon-green retro arcade interface with responsive layouts.
- Choose from five snake skins and adjust the game speed.
- Pause, restart, and game-over overlays.
- Sound toggle and saved settings/high score using LocalStorage.

## Controls

| Input | Action |
| --- | --- |
| Arrow keys or WASD | Move |
| Spacebar | Pause or resume |
| On-screen arrows | Move on touch devices |
| Restart button | Start a new run |

## Run locally

1. Clone this repository.
2. From the project root, start a local server:
   ```bash
   python3 -m http.server 8000
   ```
3. Open [http://localhost:8000](http://localhost:8000).
